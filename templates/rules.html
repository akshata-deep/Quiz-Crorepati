Quiz Crorepati — Game Rules

Read these simple rules before starting your game.

1. How to Play

  • Choose one of the six available subjects.
  • The game contains 16 multiple-choice questions.
  • Each question has four options. Select the answer you believe is correct.
  • Answer questions in order. You must answer correctly to continue.
  • You can use each available lifeline only once during a game.
  • You may choose to quit the game rather than answer the next question.

3. What Are Safe Levels?

  • Before Question 5: You have not reached the first safe level yet.
  • After answering Question 5 correctly: You secure the ₹10,000 safe prize.
  • After answering Question 10 correctly: You secure the ₹3,20,000 safe prize.
  • If you answer a later question incorrectly, your secured prize is based on the highest safe level you have already passed.
  • If you answer incorrectly before reaching the first safe level, you may finish with ₹0.
  • If you answer all 16 questions correctly, you finish with the top virtual prize of ₹7 crore.

4. Lifelines Explained

50:50

Two incorrect options are removed, leaving the correct answer and one incorrect answer. You must still choose an answer.

Audience Poll

A simulated audience poll displays how a virtual audience might vote for the options. It is only a guide and is not guaranteed to be correct.

Phone-a-Friend

A simulated friend gives you a suggested answer. The suggestion may be wrong, so think carefully before choosing.

Remember: Each lifeline can be used only once per game. Lifelines help you decide, but they do not guarantee a correct answer.

5. If You Answer Incorrectly

The game ends when you submit an incorrect answer. Your final virtual prize is determined by the safe level you have already secured. The website will show your result and save the game to your history.

6. Quitting the Game

If the game provides a quit option, you can leave before answering the next question. Your prize will depend on the game's actual quit rules and the amount already secured.

IMPORTANT: Quiz Crorepati is an educational student project. Every prize amount is virtual and is used only for the game. No real money, cash reward, or financial prize is awarded.
